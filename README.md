# Sistema de Compras em C

Projeto avaliativo desenvolvido em grupo, composto por 5 integrantes, com o objetivo de implementar um sistema de compras utilizando a linguagem C.

O sistema simula o processo de compra em uma loja de produtos eletrônicos, permitindo ao usuário selecionar produtos, calcular valores e consultar informações sobre a entrega.

## Funcionalidades

- Exibição de produtos disponíveis e seus respectivos preços promocionais.
- Seleção da quantidade de produtos desejada.
- Identificação dos produtos por código, nome e peso.
- Cálculo do subtotal e do peso total da compra.
- Cálculo automático do frete de acordo com a região de entrega e o peso total.
- Exibição do valor total do pedido.
- Registro da data e hora da compra.
- Cálculo da previsão de entrega para o dia seguinte.
- Opção para realizar novas compras.

## Conceitos de C utilizados

Durante o desenvolvimento, foram aplicados conceitos fundamentais da linguagem C, incluindo:

- Variáveis e tipos de dados.
- Estruturas condicionais (`if/else`).
- Estruturas de repetição (`for` e `do-while`).
- Estrutura de seleção (`switch/case`).
- Funções da biblioteca `stdio.h` para entrada e saída de dados.
- Biblioteca `time.h` para manipulação de datas e horários.
- Acumuladores e operações matemáticas.

## Ambiente de desenvolvimento

O código foi desenvolvido e testado utilizando o compilador online **Programiz**.
